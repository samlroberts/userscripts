# Userscripts

Browser userscripts maintained by Sam Roberts. Install a userscript by opening
its **Install** link in [Tampermonkey](https://www.tampermonkey.net/) (or a
compatible manager) and confirming the prompt. Installed scripts automatically
check the URLs below for updates.

| Userscript | Description | Install |
| --- | --- | --- |
| Gmail To/From Field Search | Makes email addresses in Gmail's To and From fields clickable searches. | [Install](https://raw.githubusercontent.com/samlroberts/userscripts/main/Gmail%20To-From%20Field%20Search.user.js) |
| Google Calendar – Drag & Drop ICS Import | Opens a dropped `.ics` file as a new Google Calendar event. | [Install](https://raw.githubusercontent.com/samlroberts/userscripts/main/Google%20Calendar%20-%20Drag%20%26%20Drop%20ICS%20Import.user.js) |
| YouTube Shorts Upload Date | Shows upload dates and freshness indicators on Shorts pages and thumbnails. | [Install](https://raw.githubusercontent.com/samlroberts/userscripts/main/YouTube%20Shorts%20Upload%20Date.user.js) |
| restoreBskyNativeVideo | Replaces Bluesky's custom video player with the browser-native player. | [Install](https://raw.githubusercontent.com/samlroberts/userscripts/main/restoreBskyNativeVideo.user.js) |

## Source and publishing

The canonical source lives in a private repository. GitHub Actions publishes
only `*.user.js` files and this README to this public repository; Tampermonkey
options and local storage are intentionally not published.
